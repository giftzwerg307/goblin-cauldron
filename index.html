Hinweise

Dies ist ein Prototyp. Der B1-Druck nutzt ein Community-Protokoll, kein offizielles NIIMBOT-SDK. Erst einen Testdruck mit einer günstigen Etikettenrolle machen.

Die App-Oberfläche kann lokal gespeichert werden, aber Bluetooth im iPhone-Browser benötigt eine sichere HTTPS-Seite und Web-Bluetooth-Unterstützung. Scryfall-Suche benötigt Internet. Sprachsteuerung hängt davon ab, ob dein Browser die Web Speech API unterstützt; sonst nutze die Texteingabe oder iOS-Diktat.
